# IZ TECH

Landing de IZ TECH: chatbots de WhatsApp y páginas web sencillas para clínicas dentales y negocios pequeños en el Perú.

Sitio: https://fab0108-create.github.io/iztech-web/

Para publicarlo, en el repositorio: Settings → Pages → Deploy from a branch → `main` → `/docs`. La portada está en `docs/index.html`, con `.nojekyll`.

`reference/old-index.html` es el volcado de la página anterior y no forma parte del sitio publicado.
