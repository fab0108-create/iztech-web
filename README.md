# IZ TECH

Landing de IZ TECH: chatbots de WhatsApp y páginas web sencillas para clínicas dentales y negocios pequeños en el Perú.

Sitio: https://fab0108-create.github.io/iztech-web/

Para publicarlo, en el repositorio: Settings → Pages → Deploy from a branch → `main` → `/ (root)`. El archivo de portada ya está en la raíz de `main`, con `.nojekyll`.

El archivo que se publica es `index.html`. `reference/old-index.html` es el volcado de la página anterior y no es la portada.
